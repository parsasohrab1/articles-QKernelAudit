# Business Requirements Specification – QKernelAudit

| ID | Requirement |
|----|-------------|
| BR-1 | Compare a quantum-kernel SVM with tuned classical SVMs under the same cross-validation and the same inputs. |
| BR-2 | Measure kernel concentration (variance of off-diagonal kernel values) as the number of qubits and the data scaling grow. |
| BR-3 | Report which bandwidth the tuning selected, to expose tuning that hides concentration. |
| BR-4 | Make no claim of quantum advantage; report the numbers as they are. |

Out of scope: hardware execution, shot noise, other feature maps, large qubit counts.
